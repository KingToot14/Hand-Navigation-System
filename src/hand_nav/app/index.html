General

Usage

Select either the "Navigation" or "Gamepad" tab at the top to launch either system. Each tab has an assortment of settings to customize your experience.

General Settings

Creates a small window off-screen that is set to be 'always on top'. This prevents slowdowns on Windows when the GUI is out of focus.

Once either the Navigation or Gamepad system starts, the GUI is minimized automatically.

Navigation

Start Capture

This is the standard navigation system this project was originally designed around. It emulates a keyboard and mouse by recognizing various hand gestures, as well as how the hand moves.

Navigation Settings

Gamepad

Start Capture

This is an addition to the original project since a primary motivator for the project was to explore new ways to interact with games. Emulating a gamepad can allow for this system to work with (theoretically) any game that supports an XBox 360 controller.

Program

This projects was developed for the 2025 IUP U-SOAR program which supports undergraduate research through workshops, project funding, and one-on-one faculty mentorship. The program took place throughout the summer of 2025 (June 11th to August 20th) over 10 weeks.

Libraries

Google's MediaPipe Main Page | Hand Landmark Detection

I used MediaPipe's Hand Landmark Detector solution in order to get key hand points from a live video stream.

OpenCV Main Page

I used OpenCV to open a live video stream and perform basic image manipulation.
